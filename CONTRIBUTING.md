# Contributing

Thanks for helping! Changes go through pull requests; nobody pushes to `main` directly.

1. Fork the repo and create a branch.
2. Make your change. Keep the scripts **read-only**: they must never change settings on the computer or router.
3. Test on your system and say which one in the pull request (macOS, Linux distro, or Windows version and language).
4. Remove personal data from anything you paste: Wi-Fi names, IP and MAC addresses, serial numbers, passwords.
5. Open a pull request. The owner reviews every change before it's merged.

Most wanted:

- Test reports from **Linux** and **Windows** (especially non-English Windows).
- Router menu paths for `references/routers.md`.
